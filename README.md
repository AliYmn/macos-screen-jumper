**Jumper** is a sleek and lightweight macOS menu bar application that lets you instantly move your mouse cursor to the center of any connected display using global keyboard shortcuts.

## Features

- Instantly move your cursor across multiple displays
- Global shortcuts (⌃⇧1, ⌃⇧2, etc.) for quick navigation
- Customizable shortcut keys
- Optional sound and visual feedback
- Auto-detection of newly connected screens
- Minimal CPU and memory usage
- Launch on system startup (optional)

## How to Use

1. Click the Jumper icon in the menu bar to view all connected screens.
2. Use the assigned keyboard shortcuts (Control+Shift+Number) to jump instantly.
3. Open **Settings** to customize shortcuts and preferences.

## Settings

- **General**: Enable or disable sound effects, visual effects, and auto-launch at login.
- **Shortcuts**: Customize shortcut keys for each connected screen.
- **About**: View app version and details.

## Requirements

- macOS 12.0 or later
- Accessibility permissions (required for capturing global shortcuts)

## Installation

1. Download the latest release.
2. Move `Jumper.app` to your Applications folder.
3. Launch Jumper and grant the required Accessibility permissions when prompted.

## Privacy & Permissions

Jumper requires Accessibility access to:
- Monitor global keyboard shortcuts.
- Move the mouse cursor between screens.

Jumper operates entirely locally. No data is collected, stored, or transmitted.
