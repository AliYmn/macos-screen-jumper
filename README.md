A lightweight macOS menu bar utility that lets you instantly move your cursor to the center of any connected display using keyboard shortcuts.

## Features

- **Quick Navigation**: Jump your cursor between displays with a simple keyboard shortcut
- **Global Shortcuts**: Use Control+Shift+Number (⌃⇧1, ⌃⇧2, etc.) to access any screen
- **Customizable**: Change keyboard shortcuts to match your workflow
- **Feedback**: Optional sound and visual effects when jumping
- **Smart Detection**: Automatically detects all connected displays
- **Efficient**: Minimal CPU and memory usage
- **Convenient**: Option to start automatically at login

## Usage

1. Click the Jumper icon in your menu bar
2. Select a screen or use the keyboard shortcut shown next to each screen
3. Your cursor instantly jumps to the center of the selected display

## Settings

Access settings through the menu bar icon:

- **General**: Toggle sound effects, visual effects, and auto-start options
- **Shortcuts**: Customize keyboard shortcuts for each connected display
- **About**: View version information and links

## Requirements

- macOS 12.0 or later
- Accessibility permissions (for keyboard shortcuts and cursor movement)

## Installation

1. Download the latest release from the [releases page](https://github.com/AliYmn/macos-jumper/releases)
2. Move Jumper.app to your Applications folder
3. Launch Jumper and follow the permission prompts

## Privacy

Jumper requires Accessibility permissions to:
- Monitor keyboard shortcuts
- Move the cursor between screens

The app does not collect any data or connect to the internet.

Jumper requires Accessibility access to:
- Monitor global keyboard shortcuts.
- Move the mouse cursor between screens.

Jumper operates entirely locally. No data is collected, stored, or transmitted.
