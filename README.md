Jumper is a lightweight macOS menu bar application that enables users to instantly move their mouse cursor to the center of any connected display using global keyboard shortcuts.

## Features

- **Multi-Screen Support**: Automatically detects all connected screens
- **Global Shortcuts**: Use Control+Shift+Number (⌃⇧1, ⌃⇧2, etc.) to jump to each screen
- **Customizable Shortcuts**: Change keyboard shortcuts for each screen
- **Visual Feedback**: Optional visual effect when jumping to a screen
- **Sound Feedback**: Optional sound effect when jumping to a screen
- **Intelligent Icons**: Shows appropriate icons based on screen type (built-in, portrait, ultrawide, etc.)
- **Low Resource Usage**: Minimal CPU and memory footprint
- **Launch at Login**: Option to start automatically when you log in
- **Dynamic Screen Detection**: Automatically adapts when screens are connected or disconnected

## Usage

1. Click on the Jumper icon in the menu bar to see all connected screens
2. Use the keyboard shortcuts (Control+Shift+Number) to jump to each screen
3. Access settings to customize shortcuts and preferences

## Settings

- **General**: Toggle sound effects, visual effects, and launch at login
- **Shortcuts**: Customize keyboard shortcuts for each screen
- **About**: Version information and app details

## Requirements

- macOS 12.0 or later
- Accessibility permissions (required for global shortcuts)

## Installation

1. Download the latest release
2. Move Jumper.app to your Applications folder
3. Launch the app and grant accessibility permissions when prompted

## Privacy & Permissions

Jumper requires accessibility permissions to:
- Listen for global keyboard shortcuts
- Move the cursor between screens

No data is collected or transmitted outside your computer.
